# Lookoom

Welcome to the **Lookoom**! This web application allows users to explore and sort through a vast collection of manga titles. Whether you're a seasoned manga reader or just starting, you'll find it easy to discover new stories and series that pique your interest.

## Features

- **Browse Manga**: Explore a comprehensive list of manga titles, including covers and descriptions.
- **Sort and Filter**: Sort manga by popularity, rating, favorite, and filter by ongoing.
- **Infinite Scrolling**: Enjoy a seamless browsing experience with infinite scrolling as you explore more titles.
- **User-Friendly Interface**: Navigate through the site with a clean, responsive design.

## Technologies Used

This project utilizes the following technologies:

- **HTML5**: For structuring the web pages.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactive elements and API requests.
- **Jikan API**: A free API that provides information about manga, anime, and more.
